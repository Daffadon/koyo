# Koyo UI audit 001 fixes

Date: 2026-11-18
Source audit: `anti-slop/audit-001-2026-11-18.md`
Scope: apply all 11 approved findings without changing the existing visual signature.

## Applied fixes

1. Light theme muted text: `#74796F` changed to `#5F665D`. Measured 5.19:1 on background, 5.48:1 on panel, 4.79:1 on sidebar. Passes 4.5:1.
2. Light theme warning and danger text: warning changed to `#7A5222`, danger to `#7F4A43`. Warning measures 5.36:1 on panel_alt and 6.36:1 on panel. Danger measures 6.56:1 on panel. Passes 4.5:1.
3. Focus and control boundaries: ring changed to `#4C7463`, input boundary to `#7A8177`. Ring measures 4.62:1 on background and 4.26:1 on sidebar. Input boundary measures 3.52:1 on background and 3.71:1 on panel. Passes 3:1 non-text contrast. Decorative panel separators keep the softer border color.
4. Keyboard access: added reusable focus handles and Tab stops to schema groups, schema nodes, schema categories, schema objects, metadata groups, history rows, table headers, table cells, table row rails, table resize handles, query cells, query row rails, and query resize handles. Enter or Space activates rows and cells. Resize handles use Left and Right arrows; Enter autosizes a table column.
5. Accessible names: tooltip buttons now set `accessibility_label` from the tooltip. Added explicit labels to result options, pagination, dialog close, and cell editor close. Added `aria_label` to search fields, connection fields, table filter, SQL editor, AI composer, AI settings JSON, and cell editor.
6. Visible field labels: added visible labels for explorer search, saved connection search, AI settings JSON, and the AI composer. Table filter already had a visible label.
7. Explorer loading state: added `catalog_loading`, set around metadata loading, and replaced the premature `No metadata found.` with a spinner and `Loading database objects...`.
8. Table loading state: added `Loading rows...` under the table spinner.
9. History status: query history detail now includes `Succeeded` or `Failed`. The colored dot remains as a secondary cue.
10. Design direction: added `DESIGN.md` with the existing identity, palette, typography, density, states, accessibility, motion, and reason log. Dials are declared as ENERGY 1 / RHYTHM 1 / MOTION 1.
11. Typography rationale: documented in `DESIGN.md`. Platform sans is used for native familiarity; platform monospace is used for SQL and data alignment.
